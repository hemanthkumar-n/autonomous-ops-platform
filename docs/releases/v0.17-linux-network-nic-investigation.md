# v0.17.0: Linux Network And NIC Investigation

Date: 2026-08-08

## Why This Release Exists

Network incidents should be investigated from the bottom up.

This release turns NIC and network evidence into deterministic findings:

```text
interface state
  -> carrier
  -> errors and drops
  -> speed and duplex visibility
  -> routes
  -> DNS resolver evidence
```

That keeps AOP from blaming Kubernetes, DNS, or applications before the host
network basics are proven.

## What Changed

New CLI path:

```bash
aop investigate linux network
aop investigate linux network --iface ens5
aop investigate linux network --iface ens5 --format json
```

New implementation:

```text
app/agents/linux/network_agent.py
app/orchestration/linux_network_workflow.py
```

New deterministic findings:

- `interface_down`
- `no_carrier`
- `interface_error_pressure`
- `speed_or_duplex_unknown`
- `missing_default_route`
- `missing_dns_resolver`
- `insufficient_evidence`

## Safety Boundary

The network investigator is read-only.

It does not:

- bring interfaces up or down
- change routes
- alter MTU
- modify offload settings
- reset drivers
- capture packets
- change DNS configuration
- modify firewall state
