# v0.23.0: Kubernetes Expert Shortcuts

Date: 2026-08-11

## Purpose

v0.23 reduces typing during Kubernetes troubleshooting.

The long commands remain useful and explicit:

```bash
aop investigate k8s-knowledge --symptom OOMKilled
aop investigate k8s-linux --incident OOMKilled
```

But an SRE under pressure needs short, memorable commands:

```bash
aop kx oom
aop kx crash
aop kx image
aop kx disk
aop kx node
```

## Added

- top-level `aop kx` command group
- `aop kx list`
- shortcut aliases for common Kubernetes symptoms:
  - `oom`
  - `crash`
  - `image`
  - `pull`
  - `config`
  - `runtime`
  - `schedule`
  - `pending`
  - `disk`
  - `memory`
  - `pid`
  - `node`
  - `notready`
  - `network`
- shortcut output that combines:
  - curated Kubernetes issue knowledge
  - Kubernetes checks
  - Linux evidence guidance
  - safe next AOP commands
  - do-not-assume reminder
- JSON output through `aop kx explain <symptom> --json`

## Boundary

This release adds usability shortcuts only. It does not add new live
collection behavior or mutate Kubernetes/Linux state.
