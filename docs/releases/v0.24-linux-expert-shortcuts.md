# v0.24.0: Linux Expert Shortcuts

Date: 2026-08-14

## Purpose

v0.24 adds short Linux expert shortcuts so AOP is useful during real incident
pressure without long command typing.

This is the Linux counterpart to `aop kx`.

## Added

- top-level `aop lx` command group
- `aop lx list`
- Linux expert shortcuts:
  - `boot`
  - `kernel`
  - `grub`
  - `grubby`
  - `storage`
  - `lvm`
  - `dns`
  - `nfs`
  - `limits`
  - `ulimit`
  - `selinux`
  - `runtime`
  - `container`
- JSON output through `aop lx explain <topic> --json`
- Linux shortcut memory at
  `app/memory/knowledgebase/linux_expert_shortcuts_catalog.md`
- tests for shortcut listing, boot/grub/storage output, and JSON guardrails

## Example

```bash
aop lx grub
```

This explains `grubby`, default kernel checks, boot arguments, rollback
requirements, Kubernetes cgroup impact, and dangerous commands to avoid.

## Boundary

This release adds knowledge and shortcut routing only. It does not change the
bootloader, restart services, repair filesystems, remount filesystems, change
SELinux mode, unmount NFS, or delete container runtime data.

## Next

Convert the highest-value Linux shortcut areas into deeper deterministic
investigators, starting with boot/kernel/grubby and storage/LVM/NFS.
