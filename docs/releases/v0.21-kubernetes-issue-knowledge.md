# v0.21.0: Kubernetes Issue Knowledge Catalog

Date: 2026-08-08

## Purpose

v0.21 adds curated Kubernetes issue knowledge before wiring that knowledge into
live incident reports.

This is the safer version of "pull online issues and train the agents": AOP
stores trusted Kubernetes troubleshooting patterns with source links, safe
commands, Linux evidence needs, and do-not-assume rules. It does not blindly
ingest every public issue thread.

## Added

- `app/agents/sre/kubernetes_issue_training_agent.py`
- `app/schemas/kubernetes_knowledge.py`
- `aop investigate k8s-knowledge`
- `aop investigate k8s-knowledge --list`
- `aop investigate k8s-knowledge --symptom <symptom>`
- JSON output for curated Kubernetes issue knowledge
- source-controlled memory at
  `app/memory/knowledgebase/kubernetes_issue_catalog.md`
- tests for the Kubernetes issue knowledge agent and CLI

- `CreateContainerConfigError`
- `CreateContainerError`
- `FailedScheduling`
- `DiskPressure`
- `MemoryPressure`
- `PIDPressure`

- `NetworkUnavailable`

## Trusted Sources

- Kubernetes Debug Running Pods
- Kubernetes Node Status
- Kubernetes Node-pressure Eviction
- Kubernetes Monitoring, Logging, and Debugging

## Boundary

This release does not scrape GitHub issues or vendor support portals. It
creates the reviewed memory format and curated baseline. External issue
ingestion should come later with filtering, source quality checks,
deduplication, and version labeling.
