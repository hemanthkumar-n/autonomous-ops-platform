# v0.36.0: Pattern Context RCA And Linux Summaries

## Purpose

v0.36.0 makes pattern intelligence more useful during active investigation.
v0.35 showed recurrence hints in Kubernetes output. v0.36 feeds a bounded
version of that recurrence context into Kubernetes RCA prompts and adds Linux
summary recurrence hints.

## What Changed

- Added bounded pattern context formatting for RCA prompts.
- Passed `pattern_guidance` into Kubernetes RCA generation.
- Added Linux recurrence hints to summary output for:
  - disk
  - memory
  - CPU
  - network
  - service
  - boot/kernel
  - host correlation
- Kept JSON schemas for individual Linux investigation outputs stable.
- Added tests for prompt context, workflow wiring, and Linux summary rendering.

## Boundary

Pattern context is intentionally short:

```text
fingerprint
recurrence count
latest timestamp
resources
severity list
boundary note
```

AOP does not dump raw memory into the prompt. Historical recurrence remains a
clue, not proof of root cause.

## Next

The next logical step is runbook/RAG retrieval:

```text
current incident
  -> pattern memory
  -> matching runbook chunks
  -> bounded RCA context
```
