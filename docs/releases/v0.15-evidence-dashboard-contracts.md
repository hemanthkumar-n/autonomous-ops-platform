# v0.15.0: Evidence And Dashboard Data Contracts

Date: 2026-08-08

## Why This Release Exists

AOP is growing beyond one CLI command at a time.

Before building dashboards, graphs, Slack/Teams cards, AWS views, or richer AI
context, the platform needs shared internal contracts:

```text
Linux evidence
Kubernetes evidence
AWS evidence
Prometheus or CloudWatch metrics
alerts
incident findings
UI panels
reports
AI context
```

All of those should use one typed shape instead of every feature inventing its
own JSON.

## What Changed

New contracts:

```text
app/schemas/evidence.py
```

Implemented models:

- `MetricPoint`
- `MetricSeries`
- `AlertSignal`
- `EvidenceItem`
- `EvidenceTimeline`
- `DashboardPanel`
- `DashboardSnapshot`

## What These Contracts Enable

These contracts are provider-neutral. They can represent data from:

- AOP Linux collectors
- AOP Kubernetes collectors
- Prometheus
- future AWS CloudWatch adapters
- future OpenTelemetry adapters
- incident reports
- semantic memory
- future UI dashboards
- future Slack or Teams notifications
- AI prompt context

## What Is Not Built Yet

This release does not add:

- a web UI
- graph rendering
- ECharts integration
- Grafana export
- CloudWatch collection
- Slack or Teams cards
- automatic alert routing

It creates the foundation those features should use.

## Validation

Added tests cover:

- provider-neutral metric series
- evidence timeline ordering
- dashboard snapshots combining alerts and evidence

This keeps the future UI path typed and testable before the UI exists.
